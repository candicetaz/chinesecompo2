# 中文句子工具箱（Chinese Compo 2）

A mobile-friendly Chinese composition learning app for Primary 5 pupils.

## Learning sections

- 扩句阶梯 — build complete sentences one layer at a time
- 结构词 — 的、地、得、了、着、过 and more
- 副词 — describe how an action is performed
- 形容词 — describe people, places and things
- 介词 — 在、从、向、朝、把、被 and more
- 关联词 — meanings, usage rules and examples
- 练习 — short questions for revision

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
